💻 Execute a Auditoria Completa de Web/TLS, Portas e Repositórios via CLI

git clone https://github.com/WallisonWS/netguard-audit.git
cd netguard-audit

# 1) Auditar TLS & HTTP Security Headers + Gerar Relatório HTML Executivo (Nota A+ a F)
python3 netguard.py audit-web https://seu-dominio.com.br --html relatorio.html

# 2) Escanear Repositório Git inteiro contra vazamento de chaves e senhas
python3 netguard.py audit-repo . --html secrets-report.html

# 3) Auditoria de Portas Críticas Expostas (SSH, SMB, RDP, DBs, Redis)
python3 netguard.py audit-ports 192.168.1.1

# 4) Windows PowerShell Nativo (Zero Python)
.\netguard.ps1 -Mode audit-web -Target "https://github.com"
